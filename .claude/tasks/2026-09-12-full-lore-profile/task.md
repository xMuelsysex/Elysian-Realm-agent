# 完整剧情原文与用户剧情档案

## 目标与决策
- 导入 `往世乐土` 与 `致以无瑕之人` 两大章的完整剧情原文，保留说话角色、旁白、系统、选项、结果等文本类型与原始顺序。
- 采用本地 `profileId` 区分用户；后台负责创建和配置档案，聊天页在多个档案存在时允许用户自行选择。
- 每个用户独立保存剧情进度、角色记忆、好感度、心情、自我认知和对话历史；新档案从零开始，不自动继承当前单用户状态。
- 每个用户使用一个按场景 / 页面推进的剧情游标，按网站小章节顺序组织，第一期由后台手动前后调整。
- 回退剧情游标时同步回退目标节点之后产生的用户状态。
- 角色按场景入场点获得原文；入场前对话默认不可知，后续原文明确转述时才可获得前情。
- 原文采用一次性本地导入，运行时不依赖外部网络。

## 计划
- 审计现有单用户 Host、SQLite 状态、聊天契约、Lore 检索和后台页面。
- 设计并实现用户档案与状态隔离、剧情游标和回退机制。
- 建立完整剧情原文的本地结构与导入流程，接入阶段 / 入场点检索。
- 补齐聊天档案选择与后台档案 / 剧情设置。
- 运行 focused 测试、类型检查、构建和实际页面验证。
