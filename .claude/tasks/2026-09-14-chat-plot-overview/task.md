# Chat 右侧剧情概述面板

## 目标与决策
- 目标：在 `/chat` 右侧提供当前剧情概述，帮助用户围绕当前剧情向角色提问。
- 桌面端显示当前角色可见剧情的 LLM 概述，并展示最近 3 个已发生场景的回顾。
- 概述和 3 个提问提示在进入页面、切换档案、切换角色或剧情进度变化后自动生成；结果不成为角色记忆或聊天历史。
- 提问提示点击后复制到剪贴板，不直接发送。
- 窄屏将侧栏折叠；游标为 0、剧情源缺失或角色没有可见原文时显示明确空状态，不用猜测内容填充。
- 项目既有剧情边界保持不变：未解锁内容、角色入场前内容和不可见角色内容不得进入侧栏。

## 计划
1. 复用现有 profile / agent / story state 与角色可见 Lore 投影，确认生成请求的最小边界。
2. 增加非持久化剧情概述数据请求和聊天页右侧响应式面板；保留现有顶部剧情卡片。
3. 通过现有测试、类型检查、构建和浏览器实测验证可见边界、空状态、响应式折叠和复制提示。
